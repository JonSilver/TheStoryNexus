# Getting Started

The Story Nexus is a writing app first and an AI app second. You keep one key in Settings, then everything else happens where you write — on a laptop or under a thumb on a phone.

> [!IMPORTANT]
> **Two minutes to writing**
>
> 1. **AI Settings** → paste one API key (OpenAI, OpenRouter or Gemini), or point it at a local model URL.
> 2. **Stories** → type a title → **Create**.
> 3. **Chapters** → **Add** → the editor opens.
> 4. Start typing. Tap the wand for AI, or the sparkles for a scene beat.

## 1. Connect an AI provider

Open **AI Settings** — it's on the **More** screen, or straight from here.

→ [Go to AI Settings](/settings)

| Provider          | What to enter                                                                                                              |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **OpenAI**        | Your OpenAI API key                                                                                                        |
| **OpenRouter**    | Your OpenRouter API key — one key, many models                                                                             |
| **Google Gemini** | Your Gemini API key                                                                                                        |
| **Local**         | The URL of an LM Studio-compatible server (default `http://localhost:1234/v1`), under **Local Models → Advanced Settings** |

One provider is enough. Saving a key immediately fetches that provider's model list and, if you haven't got a default model yet, **picks one for you**. There's no model to choose before you can write.

> [!NOTE]
> Keys live on the server and are never sent back to your browser — Settings only shows whether a key is stored, never the key itself. Everything the AI does runs server-side, which is why local models work from a phone.

For a local model, saving the URL tests the connection and fetches the models. If that fails, the server can't reach the model host — see the **Advanced** guide.

## 2. Create a story

Go to **Stories**, type a title in the box at the bottom, and tap **Create**. The new story becomes the current one and you land on **Chapters**.

Tapping any story in the list makes it current and takes you back to **Write**. There's only ever one current story, and every other screen follows it.

## 3. Create a chapter

On **Chapters**, type a title (or leave it blank for "Chapter 1", "Chapter 2"…) and tap **Add**. Creating a chapter takes you straight into it — no extra hop.

The chapter list shows each chapter's word count, or "empty". Tap one to open it.

## 4. The writing surface

**Write** is the editor. The toolbar runs along the top and scrolls sideways on narrow screens:

| Control                       | What it does                                                                     |
| ----------------------------- | -------------------------------------------------------------------------------- |
| **Undo / redo**               | Standard history, including a single undo across an accepted AI insert           |
| **Block format**              | Text, Heading 1, Heading 2, Heading 3                                            |
| **Bold / italic / underline** | Inline formatting; the buttons light up when the caret is inside that formatting |
| **Sparkles**                  | Insert a scene beat at the caret                                                 |
| **Wand**                      | Continue writing from where you are                                              |
| **Rework / Expand / Shorten** | Appear only when you've selected some text                                       |
| **Document icon**             | Summarise this chapter                                                           |
| **Bullet / numbered list**    | Lists                                                                            |
| **Minus**                     | A horizontal rule — handy as a scene divider                                     |
| **Image**                     | Upload a picture; it's stored on the server and inserted into the chapter        |

At the right-hand end of the toolbar sits the **live word count** and the **save state**: _Saving…_, _Saved_, _Save failed — retrying_, or _Edited elsewhere_.

> [!TIP]
> You never press save. Typing schedules a save about a second later, and the app also flushes your work when you switch chapters, switch tools, background the tab or close it. If you edit the same chapter on two devices at once, the second one stops saving and offers a **Reload** rather than quietly overwriting the first.

### It reopens where you left off

Close the tab, come back tomorrow, open it on your phone instead — the app restores your last story, the last chapter you had open in it, and how far down you'd scrolled.

## Getting around

Four destinations along the bottom:

- **Write** — the editor for the current chapter. The chapter title at the top is a dropdown; use it to hop between chapters without leaving the page.
- **Chapters** — the chapter list for the current story, and the box for adding new ones.
- **Stories** — every story; tap to switch.
- **More** — everything else.

**More** holds the **Story Bible**, **Brainstorm**, **Notes**, **Read this story**, the **AI Actions** advanced drawer, your **story voice**, **Export**, **AI Settings**, **Series**, and this guide.

## On a phone

The whole app is built for touch: full-height screens instead of desktop dialogs, sheets that slide up from the bottom and sit under your thumb, and safe-area padding so nothing hides behind a home indicator or notch. Nothing here needs a keyboard shortcut, a right-click or a hover.
